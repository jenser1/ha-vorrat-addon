# 🔒 Security Policy

## Unterstützte Versionen

Nur die aktuellste Version wird mit Sicherheitsupdates versorgt:

| Version | Unterstützt |
|---------|-------------|
| 1.5.x   | ✅ Ja       |
| < 1.5   | ❌ Nein     |

## Sicherheitslücke melden

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue!

### So meldest du eine Sicherheitslücke:

1. Gehe zu **[Security Advisories](https://github.com/jenser1/ha-vorrat-addon/security/advisories/new)**
2. Beschreibe die Lücke so genau wie möglich:
   - Was ist das Problem?
   - Wie kann es ausgenutzt werden?
   - Welche Version ist betroffen?
3. Ich antworte innerhalb von **48 Stunden**
4. Nach dem Fix veröffentlichen wir gemeinsam ein Advisory

### Was passiert danach?

- Ich analysiere das Problem
- Entwickle einen Fix
- Veröffentliche ein Update
- Du wirst als Entdecker genannt (wenn gewünscht)
